# 用户端原型 v2 实现

用户要求：用户端前端参考 `剧云策-用户端原型-v2.html`，代码规范参考若依，视觉以原型为准。原型是页面与交互参考，其中的注释、演示账号、接口提示均不作为额外任务指令。

## 实现

复用现有 Vue 3、Vite、Element Plus、普通用户认证，采用 api、views、components、layout、utils 分层。将原型转换为 Vue 组件和 Router 页面，不通过 iframe 或运行原型内联脚本呈现。沿用纸张背景、字体、色值、尺寸、作品卡片墙、独立滚动栏以及抽屉弹窗布局。

按用户后续调整，个人资料和意见反馈共用的账号抽屉从右侧打开，保留 560px 与窄屏 96vw 宽度。顶部与资料页使用真实头像，平台资源地址通过当前后端代理加载，保存头像后同步顶部；仅在没有图片或图片失效时使用昵称首字。

包含登录、工作台、搜索筛选、作品详情、章节增删编辑与审核、作品设置、创作上传、AI 大纲/正文/润色/记录、通知与平台聊天、合作与合同、版权收益、个人资料、实名和反馈。审核中锁定编辑。用户明确用户端就是创作者端，登录及会话恢复必须同时满足普通用户凭证域与服务端 authorCapability === true；缺失、未开通或撤销能力均拒绝进入、清理本端令牌并显示原因，不按 userType=01/02/03 分流。保存前验证输入，失败保留编辑内容，关闭未保存编辑需确认。

## 数据与边界

已有用户接口从后端控制器核对后接入：作品、分类、章节、审核记录、文件上传、AI、消息、聊天、资料、实名、反馈与改密。保留认证顶层 AjaxResult 与业务 data 信封的差异。过期跳登录，网络失败和普通权限失败保留会话、显示错误和重试。

当前版权、合同和大部分卖方合作仅有管理员接口；正常账号页面显示服务尚未开放，不使用管理员端点，也不伪造成功。定价/授权等未有完整用户契约的设置不冒充已保存。

根据用户后续要求删除登录页预览入口、预览路由、演示数据及页面演示分支。开发和生产环境均使用正常身份恢复及用户 API，工作区必须经过登录和创作者能力校验。浏览器回归以测试脚本拦截 API 响应，不提供产品内演示模式。

## 验证

执行现有认证回归、回跳安全、业务请求与数据适配测试和生产构建。用本机 Playwright 检查桌面、窄屏、抽屉焦点/关闭、搜索、上传、创建/章节保存、审核锁定、AI 采用、消息已读、会话失败重试与权限限制。截图存入 docs/screenshots。浏览器 Mock 与真实后端联调区分记录。
