# 创作上传工作区验证

实现按用户参考图使用三栏结构，并按后续要求补齐字体等文档工具及单行横向滚动。全局顶部栏保留；页内工具栏不增加头像。常用文档格式与剧本工具按实际写作顺序排列，宽屏正文限制阅读宽度，窄屏资料和 AI 使用右侧抽屉。

## 已验证

- 前端 Node 测试 24 项通过，生产构建通过。
- 原有浏览器冒烟 20 项通过，覆盖作品、章节、导入、账户、消息、权限撤销与会话等流程。
- 新工作区浏览器检查 7 组通过：三栏及单行工具栏；字体/字号/加粗/对齐及刷新恢复；分集切换与 AI 插入保留格式；1920/1440/1280/1024/768/390px 布局、工具栏箭头及菜单；恢复时清理可执行标签并保留安全格式；服务端已经保存但响应中断后不重复创建分集；审核提交确认及锁定编辑。未发现运行时异常。
- 后端生产包构建通过。新文档 Java 测试使用实际生产类和 Maven 依赖类路径运行，2 项通过，验证存储文档、纯正文、JSON 输出与历史尖括号文本。
- 隔离端口 18080 启动本次后端包，使用临时账号及作品验证真实 API 与 MySQL：字体/字号/对齐格式新增后可恢复；content 返回纯正文；数据库字数不统计标签；修改后格式保留。测试账号、角色、令牌及作品均清理，临时服务停止。

## 范围与限制

Word 常用文字与段落工具已实现；未加入表格、图片、页眉页脚等完整 Word 排版功能。DOCX 当前导入正文，原文档排版不会整体导入。人物便签仅保存在当前浏览器，可下载当前便签或已保存作品的便签存档。实际使用格式保存需要配套后端代码启动。

后端内容模块已有旧测试以两个参数调用现在的四参数 listWorks，阻断全模块测试编译。本次未修改该无关测试；生产构建及新增文档测试通过不代表后端全测试套件通过。前端原有 Element Plus 全量注册仍产生大包提示。
