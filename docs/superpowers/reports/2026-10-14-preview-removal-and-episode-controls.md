# 删除登录预览与调整分集操作

删除登录页入口、开发预览路由及匿名路由豁免、演示 API 文件、布局横幅及上下文开关。作品、AI、账户与手机换绑页面改为仅使用正常用户 API。合作和版权抽屉保留正常账号的未开放提示，删除其演示记录、合同及资金模拟操作。相关样式、专用单元测试及 README 说明同步清理。用户提供的原型参考文档保留。

默认分集名统一为「第 1 集、第 2 集…」。删除按钮位于各分集卡片右下角，与切换按钮独立，保留确认与至少一个分集。删除后默认标题按顺序更新，自定义标题保留。通过稳定的本机分集编号及当前索引调整，删除其他分集不切走或覆盖正在编辑的正文。

验证：

- `npm run gate`：23 项 Node 测试通过，生产构建成功。
- `npm run test:browser`：21 项浏览器检查通过。新增登录页无预览入口及 `/preview`、`/preview/create`、`/preview/1` 无法绕过登录检查；正常登录、权限撤销、资料、消息、导入和作品流程通过。
- `npm run test:creation`：8 组通过，包括统一默认标题、卡片右下角删除位置、删除非当前分集后正文与格式保持、桌面及窄屏布局、格式恢复、AI 插入、保存响应中断重试和审核提交。
- `npm run test:avatar`：头像加载、保存同步、刷新及失败回退通过。
- `git diff --check` 通过；应用源码不存在预览路由、上下文分支或演示数据 API 引用。测试脚本通过 Playwright 拦截正常 API，未重新引入产品预览入口。

历史验证文档记录此前功能状态，以本次记录及当前 README 为准。本次未修改后端代码。
